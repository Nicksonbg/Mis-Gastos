# Mis Gastos

App web instalable para llevar los gastos mensuales y los préstamos. Funciona sin internet y guarda los datos solo en el dispositivo (no hay datos personales en este repositorio).

Para instalarla en el iPhone: abrir la web en Safari → Compartir → "Añadir a pantalla de inicio".
Para cargar tus datos: Datos → Cargar copia… con una copia de seguridad (.json).
